# 洪恩数学 → 《二十把钥匙》移植方案

拟定：2026-11-02（Orion）。依据：洪恩数学深度调研报告（~/workspace/research_notes/hongan-math-app-research-20261102-0350/report.md，区分官方/实证/推广口径）。状态：待出品人拍板范围。

## 调研头条结论

洪恩被实证的真本事只有三件：①一节只教一个知识点、全册共用固定闭环（玩→学→练→测）；②同一概念在一节内换 3–4 个场景重复判断，重复概念不重复画面；③语音即界面（逐步指令+停顿提示）+ 操作级反馈密度（每步操作都有声画回应）。角色其实是它最弱的一环（麦斯只有旅程陪伴+救伙伴收集卡牌，无养成；讲解者是威严老爷爷）——小七的角色规格（十角色）已比它细。它的坑同样有名：玩学分离（打飞机学球体）、冲奖励乱点、练测单薄、无错题机制、BGM 盖过语音、不可跳不可退。

## 移植映射（学什么 / 我们现状 / 怎么改）

| 洪恩做法 | 我们现状 | 移植动作 |
|---|---|---|
| 固定闭环骨架 | 已有：热身→预测→实验→讲解→思考题 | 不动骨架，强化节奏与仪式感（环节切换统一转场、小七交接句） |
| 一节内换 3–4 场景重复判断 | 多数关实验只有 1–2 个场景，学会即止 | 每关实验后加「换个场景再试试」变式段（同概念、新情境、2 次判断），思考题前置 |
| 生活锚点/参照物 | 热身已有生活场景，但学完不回扣 | 每关收尾加「生活回扣」一幕：概念在真实生活里再现一次（照片风插图+一句小七语音） |
| 操作级反馈密度 | 关键节点有反馈，拖拽过程偏安静 | 加微交互层：拖动时对象辉光/轻响、到位「叮」、松手回弹，全册统一 |
| 游戏级流畅/美观 | 功能完整，视觉规范不一 | 视觉规范统一（圆角/阴影/按钮按下态/色彩梯队）+ 环节转场动画 + 达标庆祝动画定版（彩带+小七庆祝姿态） |
| 旅程叙事+救援收集 | 只有钥匙计数，无情感目标 | 加轻叙事线：20 关=小七的伙伴被「迷糊雾」吹散在 20 个地方，过关救回一个、得一张发现卡（收集册）；不做门禁、不改自由导航 |
| 家长可行动报告 | 报告页只有完成情况 | 报告页加：每关思考题错次、用时、用了几次提示——家长能看出哪关弱 |
| 错题机制 | 无（洪恩也没有） | 思考题答错的关，在报告页生成「再练一练」入口：原关变式题重练（反超项） |

## 明确不学（避坑清单）

- 贴皮小游戏（玩学分离）：我们的互动必须与概念同构，这是铁律，比洪恩强，不倒退。
- 金币/星星货币与结算页冲量：奖励保持过程性表扬+钥匙+发现卡，不做可消费货币。
- 讲解门控（不听完不能操作）、不可跳/不可退/线性解锁：与自由导航的既定规则冲突。
- 计时压迫：不加任何计时计分。
- 背景音乐：如加，必须语音时自动闪避降音量且家长可关（洪恩因此被投诉）。

## 分期

- **第一期（流畅+美观）**：微交互层、转场动画、视觉规范统一、达标庆祝定版、地图页旅程化视觉。
- **第二期（逻辑内核）**：每关变式段+生活回扣、家长报告升级、报告页「再练一练」错题入口。
- **第三期（角色与叙事）**：伙伴救援线+发现卡收集册、小七表情/姿态状态（思考/庆祝/鼓励）。
