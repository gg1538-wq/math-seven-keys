# 数学：打开世界的七把钥匙

为小学三年级孩子做的自主探索数学通识互动教材：单个离线 HTML 文件，不装 App、不联网、不注册，孩子自己点着玩着，就能走完七个数学大主题。

## 在线试玩 / 使用

- 直接打开 `index.html` 即可（可开启 GitHub Pages 在线试玩）。
- 也可以把 `index.html` 下载到 iPad / 平板 / 电脑，用浏览器打开，完全离线可用。
- 进度自动保存在本机，120 分钟的内容不用一次做完；七关全部可自由选择，不必按顺序通关。
- 过关标准：先猜一猜（预测）→ 动手做实验达标 → 思考题答对，才拿到钥匙。

## 七把钥匙（七个主题）

1. 质数与筛法 —— 数字花园里找质数
2. 莫比乌斯带 —— 一张纸带的单面奇遇（附真实纸带动手环节）
3. 无限与希尔伯特旅馆 —— 永远住得下的旅馆
4. 概率与随机 —— 骰子滚得越多越接近规律
5. 图论与哥尼斯堡七桥 —— 一笔画的世界
6. 机器学习初步 —— 教机器人按规则分类
7. 平方数 —— 9 为什么长成 3×3 方阵

每关形式各不相同：筛法动画、蚂蚁走纸带、拖客人进房间、骰子连滚统计、点桥步行、拖拽分类、方阵生长。向导“小七”全程陪伴，45 句台词为预录卡通女声（原音质内嵌，播放时按句加载）。

## 设计原则

- 互动、图片、动画在前，文字只作短句点睛，不让孩子读大段讲解。
- 先预测、再实验、后揭晓；答案不提前出现在插图、提示或反馈里。
- 字号与行距按儿童视力健康要求设计（正文 19px / 行高 1.9），关键操作支持拖拽与点选两种方式。

## 一个更大的想法

这只是三年级的一部分。数学通识教育可以有更多年级、更多主题：一、二年级的数感与图形，四、五、六年级的分数、几何与逻辑，往后还有更多。希望这个仓库是一个开始——欢迎老师、家长和开发者一起参与：提想法、试用反馈、认领一个新主题或新年级，让孩子们打开世界的钥匙越来越多。
